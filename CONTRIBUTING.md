# Como colaborar

Obrigado por ajudar a melhorar o PortfolioHUB!

## Passo a passo

1. Faça um **fork** ou, se for colaborador, clone o repositório.
2. Crie uma branch: `git checkout -b feature/minha-alteracao`
3. Faça commits pequenos com mensagens claras (`feat:`, `fix:`, `docs:`).
4. Envie a branch: `git push origin feature/minha-alteracao`
5. Abra um **Pull Request** preenchendo o modelo.
6. Aguarde a revisão. Só depois da aprovação o código entra na `main`.

## Regras

- Não envie diretamente para a `main` (ela é protegida).
- Nunca inclua senhas, tokens ou dados pessoais.
- Mantenha a estrutura de pastas e atualize o README se mudar algo.
- Seja respeitoso nas revisões e nos comentários.

## Reportar problemas

Abra uma **Issue** descrevendo o que aconteceu, o que esperava e, se possível, um print. Para falhas de segurança, siga o [SECURITY.md](SECURITY.md).
