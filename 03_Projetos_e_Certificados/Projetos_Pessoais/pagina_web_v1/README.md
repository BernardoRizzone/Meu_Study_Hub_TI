# Página Web v1.0

Primeiro projeto versionado com Git: uma página web estática de apresentação pessoal.

## Tecnologias

- HTML5
- CSS3

## Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/SEU-USUARIO/Meu_Study_Hub_TI.git
   ```
2. Abra o arquivo `index.html` desta pasta no navegador.

## Estrutura

```text
pagina_web_v1/
├── index.html
├── style.css
└── README.md
```
