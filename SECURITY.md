# Política de Segurança

## Versões suportadas

| Versão | Suporte |
|--------|---------|
| 2.x | ✅ |
| 1.x | ⚠️ somente correções críticas |

## Como reportar uma vulnerabilidade

Se encontrar um problema de segurança neste repositório ou no site do PortfolioHUB:

1. **Não** abra uma issue pública com detalhes da falha.
2. Use **Security → Report a vulnerability** neste repositório, ou envie um e-mail para bernardorizzone99@gmail.com com o assunto "Segurança PortfolioHUB".
3. Descreva o que encontrou e como reproduzir. Respondo em até 7 dias.

## Práticas adotadas

- Autenticação em dois fatores na conta proprietária
- Branch `main` protegida, com alterações via Pull Request
- Secret scanning e push protection ativos
- Nenhum segredo ou dado sensível versionado
