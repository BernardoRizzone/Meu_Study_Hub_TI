# 6 · Desafios e Soluções

| Desafio | Causa | Solução | Aprendizado |
|---------|-------|---------|-------------|
| Erro 404 no GitHub Pages | Os arquivos foram enviados dentro de uma pasta repetida, e o `index.html` não estava na raiz | Mover todo o conteúdo para a raiz do repositório e fazer novo commit | O Pages só publica a partir da raiz (ou `/docs`) |
| Links do portfólio apontando para `SEU-USUARIO` | Marcadores de exemplo não substituídos | Substituir em todos os arquivos pelo usuário real | Revisar o texto de exemplo antes de publicar |
| _(adicione os desafios da etapa final)_ | | | |
